# 灰阶铅笔淡彩人物风格提示词

## 风格定位

这个风格不是导演分镜版式，也不是纯黑白线稿。它的核心是：

**灰阶铅笔草稿 + 淡水墨晕染 + 少量淡彩 + 国风动画概念稿**

画面应该轻、淡、干净、朦胧，有手绘草稿感，但人物仍然好看，有仙侠角色设定稿的精致度。

## 通用风格词

```text
灰阶铅笔淡彩风格，国风仙侠人物概念稿，细腻铅笔线稿，淡水墨晕染，低饱和冷灰色调，少量肤色和衣料淡彩，柔和雾感，浅灰白留白背景，轻微纸张纹理，线条干净，五官柔和，发丝细腻，衣褶轻盈，画面安静克制，有古风动画设定稿质感，不厚涂，不高饱和。
```

## 画面关键词

- 灰阶铅笔淡彩
- 淡水墨晕染
- 低饱和冷灰色调
- 浅灰白留白背景

- 细腻发丝
- 轻盈衣褶
- 清冷仙侠气质
- 古风动画人物概念稿
- 安静克制

## 负面词

```text
不要厚涂，不要高饱和彩色，不要油画质感，不要写实摄影，不要赛博风，不要现代服装，不要复杂背景，不要强烈硬光，不要过度精修，不要塑料皮肤，不要漫画对白框，不要字幕，不要文字，不要分镜框，不要箭头标注。
```

## 江凡｜同画风人设图生成提示词

上传参考：`江凡.png`

```text
参考上传的江凡人物设定图，生成一张同角色的国风仙侠人物概念稿。

角色保留要求：
保留江凡的核心外观：年轻清冷男主，白衣仙侠长袍，黑色长发半束高冠，银色发冠，长发垂落，眉眼冷淡，五官精致，气质疏离克制。服装保持白色和浅灰为主，保留银灰腰封、宽袖、层叠衣襟、衣摆淡墨山水纹样、银色细节装饰。不要改变角色性别，不要改成短发，不要换成现代服装。

画风要求：
灰阶铅笔淡彩风格，细腻铅笔线稿结合淡水墨晕染，低饱和冷灰色调，少量肤色和衣料淡彩，柔和雾感，浅灰白留白背景，轻微纸张纹理。线条干净，发丝细腻，衣褶轻盈，白衣有柔和灰面层次和淡淡水墨边缘，整体像古风动画角色概念设定稿。

构图要求：
生成一张人物设定展示图，左边是大幅半身特写，右边是完整三视图。左侧半身特写占画面约35%-40%，突出眉眼、发冠、发丝、衣领、肩部刺绣和清冷气质。右侧三视图占画面约60%-65%，依次排列：正面全身、侧面全身、背面全身。三视图必须是同一角色、同一服装、同一发型、同一比例，站姿自然统一，用来展示白衣长袍、银灰腰封、宽袖、层叠衣摆、背后长发和衣摆淡墨山水纹。背景保持浅灰白留白，不要复杂场景。

情绪要求：
江凡表情平静、清冷、克制，眼神有距离感，不要笑，不要夸张悲伤，不要怒目。整体氛围安静、朦胧、干净。

负面要求：
不要厚涂，不要高饱和，不要强烈彩色，不要油画感，不要写实摄影，不要现代服装，不要复杂背景，不要过度精修，不要塑料皮肤，不要夸张特效，不要武器，不要字幕，不要文字，不要分镜框，不要箭头标注，不要改变江凡原本的人设特征。
```
