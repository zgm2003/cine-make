## 九宫格分镜最终提示词

复制下面这个 `text` 代码块。

```text
参考上传的四张图片，生成一张16:9横版 3x3 九宫格分镜图。

四张参考图分别用于：
1. 许悠然人设：浅青白仙侠长裙、黑色长发、银白花形发饰、温柔微忧气质。
2. 江凡人设：白衣仙侠长袍、黑色长发、银色发冠、清冷疏离气质。
3. 银色发簪道具：冷银色花形发簪、浅青玉坠、细银链流苏。
4. 空桥白雾湿石阶场景：湿冷青灰石桥、白雾、远处山门长阶、冷晨光。

整体画风必须和上传参考图一致：
灰阶铅笔淡彩，淡水墨晕染，低饱和冷灰色调，少量淡青和冷白淡彩，轻微纸张纹理，线条细腻但保留草稿感，画面安静、朦胧、清冷、遗憾。不要改成厚涂，不要改成高饱和彩色，不要改成写实摄影，不要改成漫画对白页。

版式要求：
3行3列九宫格，每格是一个关键镜头画面。每格只允许写很少文字：镜头编号 + 时间段。不要写对白，不要写旁白，不要写字幕，不要写长段说明，不要画对白气泡。

主题：
《他回头那一刻，我才知道是告别｜15秒离去》

人物表现规则：
许悠然主要用第一视角表现，可以出现她的手、浅青白袖口、奔跑时的衣袖、握着银色发簪的手，不要强行出现许悠然正脸。
江凡主要以远处背影、半侧轮廓、雾中白衣身影出现，不要完整露脸。
两人保持不可触碰的距离，情绪是期待、停顿、心碎、遗憾。

九宫格内容：

镜头01｜0-1.5s
第一视角冲上湿冷石桥，前景有许悠然浅青白袖口和抬起的手，远处白雾中是江凡白衣背影。桥面湿润反光，晨雾很重。

镜头02｜1.5-3s
第一视角在桥头急停，许悠然的手扶住旧石栏或石柱，画面有轻微失衡感。江凡远处停步，仍然背对她。

镜头03｜3-4.5s
中远景，江凡白衣背影在雾中微微侧身，肩线开始转动，像是终于要回头。白衣边缘被冷白晨光勾亮。

镜头04｜4.5-6s
近中景，江凡缓慢回头，但白雾遮住五官，只能看见长发、半侧下颌、白衣轮廓。不要完整露脸。

镜头05｜6-7.5s
两人隔着空桥和白雾对望。画面中间留出大片空白距离，江凡站在雾里没有向前，许悠然停在桥头。

镜头06｜7.5-9s
许悠然第一视角伸出手，指尖停在半空，抓不到江凡。远处江凡身影更淡，白雾更浓，桥面空间被拉长。

镜头07｜9-11s
银色发簪特写，许悠然手指微微发抖，发簪冷银花纹和浅青玉坠有一点冷光。远处江凡背影虚化在背景里。

镜头08｜11-13s
远景，江凡转身继续走入白雾，背影被雾吞没。空桥变得更大，人变得更小，画面留白增加，离别感加强。

镜头09｜13-15s
极近景，银色发簪落在湿冷石阶上，旁边只有水痕、薄雾和冷白光。画面不出现江凡，不出现许悠然正脸，只留下空桥和发簪，结尾留白。

整体情绪递进：
前3格：追赶和期待。
中间3格：回头但不可触碰。
最后3格：离去、失手、遗憾。
观众要感觉：她以为他回头是重逢，其实那一眼是告别。

负面要求：
不要现代元素，不要新增人物，不要热闹背景，不要对白气泡，不要字幕条，不要大段文字，不要夸张特效，不要让江凡完整露脸，不要让两人拥抱，不要让两人靠近，不要解释离开原因，不要把画面做成高饱和漫画，不要破坏上传参考图的人设和场景风格。
```

## 后续视频极简提示词

九宫格图满意后，视频可以用这个。

```text
参考上传的九宫格分镜图、江凡人设、许悠然人设、银色发簪、空桥白雾湿石阶场景，生成15秒16:9国风仙侠悲剧短片。

严格按九宫格时间轴生成：许悠然追到桥头，江凡在白雾中回头，但没有回来，最后他离开，银色发簪落在湿石阶上。整体情绪从期待转为心碎，结尾留白。

台词时间轴：
0-3s：无对白，急促脚步、晨风、湿石阶轻响。
3-6s：许悠然轻声：“你回头了。”
6-9s：江凡远声：“别等我。”
9-13s：无对白，风声变大。
13-15s：发簪落地轻响；许悠然心声：“可那一眼，是他留给我的最后一眼。”

限制：
不要字幕，不要现代元素，不要新增人物，不要让江凡完整露脸，不要让两人靠近，不要解释他为什么离开。台词只能在指定时间出现，不要提前，不要延后。
```
